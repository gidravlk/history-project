# Руководство пользователя по веб-проекту "История Казахстана"

## 1. Описание проекта
Данный веб-проект предназначен для проведения тестирования и написания эссе по курсу «History of Kazakhstan». Главное преимущество проекта — он работает **без базы данных, серверов и сложной инфраструктуры**. Все данные студента (эссе, результаты) сохраняются локально в его браузере с помощью `localStorage`.

Проект позволяет пользователям:
- Изучать темы курса и писать эссе на английском языке.
- Проходить тесты из 30 вопросов по выбранной теме.
- Если вопросов для темы пока нет — легко переключиться на готовую тему без потери уже написанного эссе.
- Просматривать результаты тестирования.
- Экспортировать оценки в формате CSV для Excel (с поддержкой любых символов) и сохранять их в PDF.

---

## 2. Структура проекта
В папке сайта находятся следующие файлы:
- `index.html` — Главная страница (выбор темы и ввод Full Name и Group).
- `essay.html` — Страница для написания эссе и получения симуляции "оценки ИИ".
- `quiz.html` — Страница тестов (или меню смены темы, если для исходной темы вопросы ещё не написаны).
- `results.html` — Страница итоговой таблицы результатов студентов, сохраненных на этом устройстве.
- `data.js` — Хранилище тем и вопросов (здесь хранится весь контент курса).
- `script.js` — Вся логика работы сайта, управление `localStorage` и экспорт.
- `style.css` — Мобильно-адаптивный дизайн + стили для вывода таблицы на печать без прокрутки.
- `GUIDE.md` — Данное руководство.

> **Важно:** Никаких дополнительных сборок или установки `node_modules` не требуется. Сайт запускается простым двойным кликом по файлу `index.html`.

## 3. Передача проекта следующей команде
Сайт спроектирован так, чтобы его было легко передавать между студентами. 

**Как передать проект:**
1. Поместите все файлы в `.zip` архив и отправьте следующей команде.
2. ИЛИ загрузите файлы на GitHub и предоставьте соавторам доступ к репозиторию (рекомендуется). Вы можете бесплатно опубликовать проект для всех через GitHub Pages (Settings → Pages → Deploy from branch `main`).

## 4. Как добавлять новые вопросы (Для следующих команд)
На данный момент полностью готовы тесты для Тем 1, 2, 3 и 4. Остальные темы ожидают заполнения.
Чтобы добавить 30 вопросов для новой темы:

1. Откройте файл `data.js` в любом текстовом редакторе.
2. Спуститесь к объекту `const QUIZ_BANK = { ... }`.
3. Добавьте новый блок с номером темы (например, `5: [ ... ]`), строго соблюдая структуру:

```javascript
  5: [
    { 
      q: "Текст вопроса на английском?", 
      options: ["Вариант A", "Вариант B", "Вариант C", "Вариант D"], 
      correct: 0 
    },
    // ... и так далее, ровно 30 вопросов
  ]
